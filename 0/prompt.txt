mise global minimum release age overrides per-tool setting?

No. The per-tool minimum_release_age overrides the global setting, not the other way around.

For example, in mise.toml:
[settings]
minimum_release_age = "7d"

[tools]
node = "latest"                                 # 7 days
python = { version = "latest", minimum_release_age = "3d" }
bun = { version = "latest", minimum_release_age = "0s" }

The precedence is:

    CLI --minimum-release-age (highest priority)

    Per-tool minimum_release_age

    Global [settings].minimum_release_age

    Built-in default (24h)

This is confirmed by mise's current implementation and documentation.

No, minimum_release_age should also apply to the initial installation, provided you're installing a fuzzy version such as latest.

For example:
[settings]
minimum_release_age = "7d"

[tools]
node = "latest"

On a fresh mise install, Node should respect the 7-day restriction, while Bun should install the latest stable release.
